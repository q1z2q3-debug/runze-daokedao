# 四层超越路径与验收

## 总原则

不拼“收录数量”，拼“可核验、可引用、可被模型按卷取用”。每一层都要有可验收的产物，不做“优化一下”的空话。

## 第 1 层：基础可抓取（本地 11/11，首页线上抽查通过）

| 项 | 产物 | 验收 |
|---|---|---|
| 页面 head | canonical、description、OG、Twitter、robots、citation_* | 8 站首页/全书页/前言页齐全；无重复 meta |
| 结构化数据 | Book、WebSite、BreadcrumbList、Article | JSON-LD 可解析；版本、作者、许可一致 |
| 发现文件 | sitemap.xml、robots.txt、ai.txt | 甲骨文 85 URL；八站 ai.txt 可读 |
| 甲骨文入口 | 新版首页 + 77 卷独立页 | 首页 13.6KB；卷页可单独打开 |

**已推进**：本地 11/11 已 push；八站首页线上抽查 200，canonical 正确；甲骨文 v01/v77 线上 200。千字文全书页 9.4MB 仍有传输截断。

## 第 2 层：证据可核验（下一轮重点）

| 项 | 产物 | 验收 |
|---|---|---|
| 逐字证据卡 | 905 个唯一字各一页 | 每页四行：字形来源、字源判断、同片释文、后世义层 |
| 置信度标签 | `已核 / 中 / 待核` | 可按标签筛选；不把“中”写成“已核拓片” |
| 拓片补证 | 10—20 个重点字的史语所/国图拓片 | 原图 + 摹本 + 释文三对照；来源与许可登记 |
| 卷—字内链 | 字页 ↔ 卷页 ↔ 全书 | 三级互链；无孤立页 |

**为什么先做 10—20 字，不做 905 字一起上**：拓片核对是重活，先把方法跑通，再批量复制；否则会把“待核”批量写成“已核”，反而毁掉可信度。

## 第 3 层：引用可稳定（P0/P1）

| 项 | 产物 | 验收 |
|---|---|---|
| cite/ 页 | 八书各一页 | 建议引用格式、版本、发布日期、许可、稳定 URL、BibTeX、CFF |
| 版本页 | 每书 `version` / `datePublished` / `bookEdition` | 与仓库 tag 一致 |
| feed.xml | 八站各一 | 最近 20 条更新；可订阅 |
| DOI/Zenodo | 每个 Release 存档 | 有 DOI；与 GitHub Release 对应 |

**现状**：易传有 cite/；其余七部待建。八站 feed.xml 全缺。

## 第 4 层：模型可取用（P2）

| 项 | 产物 | 验收 |
|---|---|---|
| llms.txt | 八站统一格式 | 书名、版本、许可、入口、分卷索引 |
| ai.txt | 检索/引用/训练边界 | 明确“商业训练需书面许可” |
| 分卷 JSONL | 每卷一个 JSONL | 字段：卷号、字位、字头、置信度、正文、许可 |
| 引用语料包 | 每书 `corpus/` | 只含原创正文；第三方素材单列，不混入 |

**边界**：允许模型检索、引用、非商业研究；商业训练/商业分发需书面许可。第三方拓片、字形库、AI 图、图版、字体不随本书授权。

## 验收口径

1. 本地 `audit.py` 11/11 不等于线上通过；线上必须 `curl` 验证 canonical/OG/JSON-LD。
2. 每个新增页必须有唯一 title、description、canonical；不允许复制同一 description。
3. 每一条“已核”必须有拓片/摹本/释文三源至少两源；只有字形库的标“中”。
4. 所有第三方素材进 `RIGHTS-REGISTER.csv`；未登记不得上图。
5. 所有改动可复现：脚本 + 配置 + 审计报告，不靠手工记忆。
