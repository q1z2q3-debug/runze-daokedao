# 版权登记与证据保全建议

## 是否需要登记

中国著作权自作品完成时产生，登记不是权利产生的必要条件；但登记证书在平台投诉、诉讼、行政查处和商业尽调中是低成本、强证明力的证据。

建议优先登记：

- 《润泽说 道可道之甲骨文》整体（或按卷登记，视预算）；
- 《润泽说 道可道之道德经心法读本》；
- 《润泽说 道可道之易传》《庄子》《金刚经》《坛经》《心经》；
- 《润泽说 蒙学之千字文》。

## 登记前

- [ ] 确认作品为原创，第三方素材已剔除或已获授权；
- [ ] 保存创作底稿、版本记录、Git 提交、哈希清单；
- [ ] 统一作品名称、作者署名、完成日期、首次发表信息；
- [ ] 不把第三方拓片、图版、字体、AI 生成图作为“原创内容”登记；
- [ ] 如为合作作品，先签清权属文件。

## 材料清单

- 作品登记申请表；
- 作者身份证明；
- 作品样本（文字作品可提交全文或前后各若干页 + 目录）；
- 作品说明书（创作意图、独创性、完成时间）；
- 权利归属证明（如合作作品、职务作品）；
- 委托书（如委托代理）；
- 版本哈希与公开链接（辅助证据）。

## 登记后

- 把登记号写进 `CITATION.cff`、商业许可合同附件、站点版权页；
- 登记不替代合同；商业许可仍须逐笔签署；
- 发现侵权时，登记证书 + 哈希 + 公开时间 + 侵权截图形成证据链；
- 每新增一卷或重大修订，评估是否做变更/新登记。

## 更强证据

- 可信时间戳（TSA）；
- 公证处证据保全；
- 区块链存证；
- 邮政特快专递自寄保存（传统但低成本）。

## 说明

本文件是操作建议，不是法律意见；具体登记类别、材料与费用以中国版权保护中心及当地受理机构的最新要求为准。
