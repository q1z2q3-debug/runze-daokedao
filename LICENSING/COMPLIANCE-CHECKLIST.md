# 商业许可合规检查清单

## A. 对外报价前

- [ ] 确认对方主体全称、统一社会信用代码、注册地、实际控制人、最终用途。
- [ ] 确认对方是商业主体还是个人研究；不能仅凭“模型免费”认定为非商业。
- [ ] 确认用途：预训练 / 微调 / 蒸馏 / 评测 / RAG / 商业分发 / 内容转载。
- [ ] 确认模型范围：基础模型、参数规模、模态、是否开源权重、是否对外 API。
- [ ] 确认地域、期限、渠道、语种、是否独家、是否可转授权。
- [ ] 确认是否涉及跨境、出口管制、制裁名单、上市公司披露、政府/国企采购。
- [ ] 确认对方是否已有同类许可、是否正在被作者授权、是否存在权利冲突。
- [ ] 查 [`RIGHTS-REGISTER.csv`](RIGHTS-REGISTER.csv)，把第三方素材从报价范围中剔除。
- [ ] 确认报价覆盖：固定费、分成、审计成本、律师费、税费、发票类型。
- [ ] 确认不承诺“模型训练效果”“模型不侵权”“输出一定准确”等结果性保证。

## B. 签约前

- [ ] 使用 [`contracts/商业训练许可协议-模板.md`](contracts/商业训练许可协议-模板.md)，不使用口头条款。
- [ ] 许可范围写成正面清单：书库、卷次、版本、文件、模型、用途、地域、期限。
- [ ] 明确非独占；如独家，单独写独家条款、最低保底、场域限制、终止与回授。
- [ ] 明确不可转授权、不可再许可、不可转让，除非另写。
- [ ] 明确署名方式、模型卡/数据集卡要求、引用格式。
- [ ] 明确输出限制：不得大量逐字复制、不得替代原书、不得去除署名。
- [ ] 明确第三方素材除外清单；要求对方自行清权或从语料中剔除。
- [ ] 明确付款节点、发票、逾期利息、暂停履行、解除权。
- [ ] 明确审计权、记录保存、审计频率、保密。
- [ ] 明确数据安全、泄露通知、删除/销毁、子处理者。
- [ ] 明确知识产权归属：作品文本归作者；模型权重归属按双方约定；不得把作者文本注册为对方作品。
- [ ] 明确终止后处理：停止新增训练、删除/保留模型、过渡期、尾款、署名存续。
- [ ] 明确责任上限与例外：知识产权、保密、故意/重大过失、人身损害不设上限。
- [ ] 明确适用法律与争议解决；跨境交易单独复核。
- [ ] 双方律师复核；保留签章版、附件、付款凭证、往来邮件。

## C. 签约后

- [ ] 建立合同台账：合同编号、主体、范围、期限、费用、付款日、审计日、续约日。
- [ ] 交付许可作品清单、版本号、哈希、第三方除外清单。
- [ ] 开具合规发票；确认付款到账；记录分成基数与结算。
- [ ] 要求对方提供模型卡/数据集卡样本，检查署名与许可标注。
- [ ] 约定第一次审计时间；保存审计记录。
- [ ] 监控公开渠道：GitHub、HuggingFace、模型平台、应用商店、课程平台。
- [ ] 发现超范围使用，按 [`ENFORCEMENT.md`](ENFORCEMENT.md) 取证，不先公开指控。
- [ ] 到期前 60 日启动续约或不续约通知；不自动续期。

## D. 发布前

- [ ] 每个书库根目录有 `LICENSE`、`NOTICE`、`llms.txt`、`CITATION.cff`。
- [ ] `NOTICE` 写明“商业训练/商业分发需书面许可”。
- [ ] 站点有许可页面与联系方式。
- [ ] 第三方素材有来源、许可、署名、除外声明。
- [ ] AI 生成图有标识；平台条款允许当前使用方式。
- [ ] 字体、图标、代码依赖有许可清单。
- [ ] 不把“CC BY-NC-SA”写成“OSI 开源”或“可自由商用”。
- [ ] 不把“非商业”写成“只要不收费就可以”。
- [ ] 不在模型卡/产品页暗示作者背书。

## E. 红线

- 不与对方“先训练、后补合同”。
- 不接受“先上线、后续再谈署名”。
- 不接受“只改一个字就不算改编”。
- 不接受“模型权重开源所以不用付费”。
- 不接受“我们只做评测，不算商业使用”而不看评测结果是否进入商业产品。
- 不接受“第三方素材我们一起授权”而不提供权利链。
