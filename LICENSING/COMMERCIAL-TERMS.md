# 商业许可总则

版本：2026-11-20  
适用作品：《润泽说 道可道》系列八部书库中的**原创文本、注释、编排与作者自有权属的插图**。  
不适用：第三方拓片、摹本、字形库、外部图版、字体、AI 生成图及其他按原许可使用的素材。

## 一、两层许可

### 1. 公开层：CC BY-NC-SA 4.0

非商业阅读、研究、教学、引用、非商业模型实验，按 CC BY-NC-SA 4.0 执行：署名、非商业、相同方式共享。

### 2. 商业层：书面商业许可

下列行为不属于公开层自动授权，须事先取得书面商业许可：

- 以商业目的预训练、继续预训练、微调、指令微调、RLHF、蒸馏、合成数据生成、评测集构建；
- 将作品用于商业模型、商业 API、商业 SaaS、商业插件、商业 Agent、商业课程、付费专栏、付费社群；
- 将作品或其主要内容用于商业产品的检索库、知识库、问答库、推荐系统；
- 商业性复制、汇编、改写、翻译、有声化、视频化、图像化、课程化；
- 商业性再分发模型权重、数据集、嵌入向量、索引文件；
- 以“润泽说”“道可道”“润泽博士”名义做商业背书、联名、招生、咨询。

## 二、商业许可的类型

| 类型 | 典型用途 | 默认边界 |
|---|---|---|
| 内部训练许可 | 企业内部模型、内部知识库、内部评测 | 非独占；不得对外提供模型或数据；不得转授权 |
| 产品训练许可 | 对外商业模型、API、SaaS、Agent | 非独占；限定模型/产品/地区；可约定收入分成 |
| 内容分发许可 | 付费平台转载、课程、出版、有声、视频 | 非独占；限定渠道、期限、语种、载体 |
| 品牌合作许可 | 联名、课程、活动、咨询 | 单独签约；不得暗示作者为合作方产品背书 |
| 独家许可 | 某一场域排除他人使用 | 仅在单独“独家条款”下；必须最低保底、期限、终止与回授 |

**默认一律为非独占。** 未写明“独占”的，不得解释为独占；未写明“可转授权”的，不得转授权；未写明“可修改”的，不得改编。

## 三、商业训练许可的核心边界

1. **训练目的**：写明是预训练、微调、蒸馏、评测、合成数据，还是仅做 RAG 检索；不同目的分别计价。
2. **模型范围**：写明基础模型、参数规模、模态、是否对外、是否开源权重；新增模型或重大版本升级须补充许可。
3. **数据范围**：写明书库、卷次、版本号、文件清单；不在清单内的内容不授权。
4. **地域与期限**：写明全球或特定法域、许可起止日；不得默认永久、全球、全媒体。
5. **输出限制**：不得大量逐字复制作品、不得以模型输出替代原书阅读、不得去除署名与版本信息、不得把作者解释体系伪装成模型自有知识。
6. **模型卡与引用**：模型卡、数据集卡、产品页应注明“训练语料包含润泽《润泽说 道可道之〇〇》vX.Y.Z”，并在输出引用时保留书名、版本、仓库链接。
7. **审计**：被许可方保存训练记录、模型版本、收入与分发记录；许可方每年可审计一次，提前十个工作日通知。
8. **终止后**：停止新增训练与更新；已训练模型的继续使用、删除或过渡期，必须在合同中明确，不得留白。

## 四、费用框架

以下为报价框架，不是固定价格，也不是要约：

| 场景 | 计费方式 | 备注 |
|---|---|---|
| 内部训练/内部知识库 | 年度固定费，按模型数量、参数量、使用人数分档 | 不含对外分发 |
| 对外产品/API | 年度固定费 + 收入分成，或按调用量 | 分成基数、扣除项、结算周期写清 |
| 内容分发 | 一次性许可费或按渠道收入分成 | 限定语种、渠道、期限 |
| 独家 | 最低保底 + 更高固定费 + 里程碑 | 必须限定场域与期限，不默认永久 |
| 品牌联名 | 固定费 + 销售分成 + 素材审核 | 不得暗示作者背书 |

**不建议**：永久、全球、全媒体、不可撤销、可自由转授权的“买断式”授权。若对方坚持，价格应显著高于非独占，并保留作者自用、教学、出版、后续版本的权利。

## 五、署名规范

推荐格式：

> 润泽（润泽博士）.《润泽说 道可道之〇〇》vX.Y.Z，2026。  
> 仓库：https://github.com/q1z2q3-debug/daokedao-<篇名>  
> 许可：CC BY-NC-SA 4.0；商业使用另经书面许可。

模型卡/数据集卡至少包含：作品名、作者、版本、仓库、许可、商业许可状态、第三方素材除外声明。

## 六、第三方素材

本书库中的以下类别**不自动进入商业许可**：

- 甲骨拓片、摹本、同片释文、合集号对应的图像与数据；
- JGW、EVOBC 或其他字形库的字形与派生 SVG；
- 外部图版、扫描件、地图、照片、绘画；
- 字体、图标、代码依赖；
- AI 生成插图及其平台条款覆盖的成果。

处理顺序：先查 [`RIGHTS-REGISTER.csv`](RIGHTS-REGISTER.csv)；能清权的清权，不能清权的从商业训练语料中剔除或替换。合同附件必须列明“第三方素材除外清单”。

## 七、违约与终止

- 超范围使用、转授权、未付款、未署名、拒绝审计、泄露数据、以作者名义误导背书，均构成违约。
- 许可方可要求整改、暂停履行、解除合同、删除数据/模型、赔偿损失。
- 解除不影响已产生的付款义务、保密义务、署名义务与争议解决条款。
- 具体违约金、责任上限、终止后处理以双方签署的合同为准。

## 八、争议解决

默认适用中华人民共和国法律。争议先协商三十日；协商不成，向许可方住所地有管辖权的人民法院起诉。跨境交易、境外主体、境外履行、仲裁安排或适用域外法的，不适用本默认条款，须单独设计并复核。
